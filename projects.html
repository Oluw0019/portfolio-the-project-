Overview

For Assignment #1 and Assignment #2, I developed a fully interactive Yatzy game that allows players to roll dice, hold selected dice, calculate scores based on standard Yatzy rules, and track turns. In Assignment #2, I expanded the project by migrating the dice module to a client-server architecture, enabling my game to communicate with a backend service for dice generation.

The game demonstrates key concepts in front-end development, asynchronous programming, modular design, and server communication, while maintaining a clean user interface built with reusable components from my design system.

Technical Documentation

Key Technologies Used

Front-End

  • HTML5
    Used for structuring the Yatzy interface with semantic elements to improve readability and accessibility.
  • CSS3
    Styled the game board, dice layout, buttons, and score tables. Media queries and Flexbox were used to keep the interface responsive across screen sizes.
  • JavaScript (ES6)
    Used for all gameplay logic, including:
    • Dice rolls
    • Tracking held dice
    • Roll limits
    • Score category calculations
    • DOM updates
  • JavaScript DOM Manipulation
    Updated dice visuals, score displays, and roll counts in real time based on player actions.
  • JavaScript Asynchronous Programming
    In Assignment #2, async/await was used to communicate with the server for dice rolls, ensuring non-blocking UI updates.
  • JSON
    Used to send and receive structured dice data between client and server.

Client–Server Technologies (Assignment #2)

  • Node.js & NPM
    Set up the backend environment and managed required packages.
  • Express.js
    Built the API endpoints that return random dice rolls for the client. Implemented RESTful routes following clean API design principles.
  • REST API Design
    Created endpoints for generating dice values and returning them as JSON objects.
  • MVC (Model-View-Controller) Architecture
    Followed an MVC-inspired structure to keep:
    • Models for dice state
    • Controllers for game logic
    • Views for updating UI
    This separation improved maintainability and clarity.

Tools + Development Workflow

  • VS Code
    Used as my primary code editor, leveraging extensions such as Live Server and Prettier.
  • Git & GitHub
    Used GitHub for version control, documentation, and storing the project publicly as part of my portfolio.

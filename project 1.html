Hospital Triage App — Project Summary

Overview

The Hospital Triage App was developed for Assignment #3. It is a full-stack web application that helps emergency room staff organize patients based on two key factors: severity of condition and time spent waiting. The system provides administrators with complete queue visibility and management tools, while patients can log in using their name and access code to view real-time wait time estimates.

The application demonstrates practical understanding of client-server architecture, RESTful API design, priority queue algorithms, and modern UI design patterns.

Technical Documentation

Backend (Node.js & Express)

The server was built using Express.js and provides RESTful API endpoints for managing patient data. All data is exchanged in JSON format. The application follows an MVC-inspired structure to separate concerns between data models, business logic, and views.

Key API Endpoints:

  • GET /api/patients — Retrieve all patients with calculated wait times
  • POST /api/patients — Add new patient and generate access code
  • DELETE /api/patients/:id — Remove patient from queue
  • POST /api/patient/lookup — Patient authentication and status lookup
  • GET /api/patient/:id — Get specific patient information

Priority Queue Algorithm

Patients are sorted using a two-tier priority system: severity level first (Critical, Emergency, Urgent, Non-Urgent), then arrival time. The algorithm dynamically recalculates queue order and wait times whenever patients are added or treated. Wait times are estimated based on the number of patients ahead and their expected treatment durations.

Frontend (HTML, CSS, JavaScript)

The client interface consists of three views: a landing page, admin dashboard, and patient portal. JavaScript handles all dynamic updates through asynchronous fetch requests to the API. The design uses modern glassmorphism effects with CSS backdrop filters, animations, and responsive layouts built with Flexbox and CSS Grid.

Key Features: Real-time auto-refresh for both admin and patient views, form validation, error handling, and mobile-responsive design.

Design System Integration

The portfolio's design system from Deliverable #2 was partially reused for structural elements like cards and navigation. However, the Triage App introduced a new visual style with glassmorphism effects, gradient backgrounds, and animated components that differ from the main portfolio aesthetic.

New Design Elements Added:

  • Purple-to-pink gradient backgrounds
  • Frosted glass and navy blue cards were used
  • Severity-based color coding (red, orange, yellow, green, purple, blue)
  • Smooth hover animations and transitions
  • Custom form styling with focus effects

These new components have been documented as an extension to the original design system.

Yatzy Game — Project Summary

Technical Documentation

Front-End (HTML/CSS/JavaScript)

The game interface uses Flexbox layouts and reusable button components from my portfolio design system. JavaScript handles all game logic including rolling dice, selecting which dice to hold, tracking turn limits, calculating scores for different Yatzy categories, and updating the DOM in real-time based on player actions.

Client–Server Integration (Assignment #2)

In Assignment #2, the dice rolling module was replaced with asynchronous fetch calls to a server endpoint. The server generated random dice values and returned them in JSON format. The client received the data and updated the UI accordingly, demonstrating practical understanding of API communication and asynchronous JavaScript.

Server Implementation

The backend was built using Node.js and Express, following RESTful API principles. The server handled dice generation requests and maintained consistent response formats for seamless client integration.

Design System Integration

Typography, color palette, and card components from my portfolio's design system were reused in the Yatzy interface to maintain visual consistency across projects. The button styles and spacing rules were applied directly from the established design system.

Technologies & Concepts Applied

  • JavaScript ES6 features (arrow functions, template literals, async/await)
  • DOM manipulation and event handling
  • RESTful API design and implementation
  • Asynchronous programming with Fetch API
  • Responsive design for mobile and tablet layouts
  • Git version control workflow

Highlights & Challenges

Key Achievements

  • Implemented complete Yatzy scoring logic with all categories
  • Successfully integrated client-side game with server-generated dice
  • Created smooth transitions between game states
  • Built a clean, intuitive user interface using design system components

Challenges Overcome

  • Managing asynchronous dice rolls without disrupting game flow

Reflection

The Yatzy Game project introduced fundamental JavaScript development concepts including DOM manipulation, event handling, and game logic implementation. This project established a strong foundation in full-stack development patterns and demonstrated how frontend interfaces communicate with backend services through well-designed APIs.

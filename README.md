# Danny Smith — Portfolio (Lab 3)

This repository contains a small multi-page portfolio website for CST 3106 Lab 3.

Pages included
- `myportfolio.html` — Main / Home page (featured projects)
- `about.html` — About Me page
- `resume.html` — Resume page (includes a placeholder download link)
- `contact.html` — Contact page with a simple contact form

How to open
1. Place project images in an `images/` folder (example names: `project1.png`, `project2.png`, `project3.png`, `profile.jpg`).
2. Open `myportfolio.html` in your browser.

Notes
- Styles are in `styles.css`.
- The contact form currently has a placeholder action. To enable submissions, wire it to a backend or Formspree.

If you want, I can add placeholder images and a sample PDF for the resume so the pages display fully without additional setup.
